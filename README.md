# دارا (Dara)

داشبورد فارسی مدیریت پرتفوی و گردش حساب، با گزارش تطبیق سرمایه و امکان بررسی و ویرایش ردیف‌های نیازمند اصلاح. داده‌های پرتفوی در `localStorage` همان مرورگر ذخیره می‌شوند؛ این حافظه **رمزگذاری‌شده نیست** و جای نسخهٔ پشتیبان را نمی‌گیرد.

## دانلود نسخه

1. صفحهٔ [Releases دارا](https://github.com/mjavidnazar/Dara/releases) را باز کنید و نسخهٔ موردنظر را انتخاب کنید.
2. در قسمت **Assets**، روی **Source code (zip)** بزنید و فایل را از حالت فشرده خارج کنید.
3. این ZIP **کد منبع** است، نه برنامهٔ نصب‌شدنی یا فایل اجرایی مستقل. داده‌ها و نسخه‌های پشتیبان شخصی شما داخل آن نیستند.

## اجرا روی رایانه

به [Node.js](https://nodejs.org/) نسخهٔ **22.13 یا جدیدتر** و npm نیاز دارید. در ترمینال، داخل پوشهٔ استخراج‌شده اجرا کنید:

```bash
npm ci
npm run dev
```

سپس `http://localhost:3000` را در مرورگر همان رایانه باز کنید. برای متوقف‌کردن برنامه در ترمینال `Ctrl+C` را بزنید. با `npm run build` می‌توانید ساخت نسخهٔ تولیدی را بررسی کنید. این پروژه یک برنامهٔ Next.js است؛ برای اجرای تولیدی از خروجی `standalone` همراه فایل‌های `public/` و `.next/static/` استفاده کنید.

> اگر فایل JSON پشتیبان خود را دارید، آن را **فقط در خود برنامه** از بخش «پشتیبان‌گیری» و پس از تهیهٔ نسخه از داده‌های فعلی بازیابی کنید. فایل پشتیبان شخصی، `.env` یا اطلاعات مالی را در مخزن عمومی GitHub بارگذاری نکنید. برچسب‌های خطا فقط برای بررسی‌اند و داده‌ای را خودکار اصلاح نمی‌کنند.

## جابه‌جایی معاملات هم‌روز

در بخش «معاملات»، جدول را بر اساس «تاریخ معامله» مرتب کنید. دستگیرهٔ کنار ردیف را با ماوس یا لمس بکشید، یا از دکمه‌های بالا/پایین (و کلیدهای جهت‌نما هنگام تمرکز روی دستگیره) استفاده کنید. جابه‌جایی فقط میان ردیف‌های **همان روز** انجام می‌شود؛ هنگام فعال بودن فیلتر، حرکت نسبت به ردیف‌های نمایان است.

ترتیب انتخاب‌شده در همین مرورگر و در خروجی پشتیبان JSON ذخیره می‌شود. این تنظیم فقط **ترتیب نمایش** را عوض می‌کند؛ تاریخ، ساعت، مبلغ، تسویه و محاسبات مالی را تغییر نمی‌دهد و برای معاملات فاقد ساعت، ساعت ساختگی نمی‌سازد. ردیف‌هایی با شناسهٔ تکراری تا رفع ابهام قابل جابه‌جایی نیستند.

## اولویت قیمت‌های هم‌روز

برای ارزش‌گذاری دارایی و سهام، ابتدا **جدیدترین تاریخ معتبر** انتخاب می‌شود؛ اگر برای آن روز چند قیمت ثبت شده باشد، **آخرین قیمتی که ثبت یا ویرایش کرده‌اید** مبنای محاسبات و نمودار است. ثبت قیمت تازه، قیمت‌های قبلی را حذف نمی‌کند؛ ویرایش یک رکورد نیز به رکوردهای دیگر دست نمی‌زند. ترتیب ثبت/ویرایش در پشتیبان JSON و پس از بارگذاری دوباره حفظ می‌شود. برای پشتیبان‌های قدیمی که زمان ثبت قیمت ندارند، آخرین رکورد موجود در آرایهٔ همان روز به‌طور قطعی انتخاب می‌شود. قیمت نامعتبر یا مربوط به آینده همچنان در گزارش برای اصلاح نمایش داده می‌شود و در ارزش‌گذاری به کار نمی‌رود.

## درصد سود کارت دارایی‌ها

برای دارایی‌های غیرنقدی **به‌جز کارت «بورس»**، درصد سود کارت‌ها برابر است با **(سود/زیان کلِ همان دارایی ÷ مجموع بهای همهٔ خریدهای ثبت‌شدهٔ آن) × ۱۰۰**. برای دارایی کاملاً فروخته‌شده نیز بهای خریدهای تاریخی مخرج است، نه بهای تمام‌شدهٔ موجودی فعلی که صفر شده؛ بنابراین فروش کامل به‌خودی‌خود ۱۰۰٪ سود نمی‌سازد و زیانِ فروش کامل هم صفر نمایش داده نمی‌شود. درصد **کارت بورس** دقیقاً نسبت سوم میزکار بورس است: سود کل بورس ÷ بیشترین پول درگیر بورس. هیچ‌یک بازده سالانه یا بازده سرمایهٔ اولیهٔ کل سبد نیستند؛ نسبت‌های اختصاصی گزارش سرمایه فرمول‌های جداگانهٔ خود را دارند. مبالغ سود، معاملات و مانده‌ها با تغییر مخرج دستکاری نمی‌شوند.

## سه نسبت سود در میزکار «بورس»

سه نسبت مستقل با **صورت و مخرجِ نمایان** نمایش داده می‌شوند. «بیشترین پول درگیر بورس» یعنی **بیشینهٔ جمع بهای تمام‌شدهٔ سهامِ هم‌زمان موجود در پایان یک روز** از ابتدای سفارش‌های معتبر تا امروز. خریدها با مبلغ تسویه (شامل هزینهٔ خرید ثبت‌شده) به بهای موجودی اضافه می‌شوند؛ فروش، بهای میانگین سهم‌های فروخته‌شده را کم می‌کند، نه کل مبلغ فروش را. این اوج برای **کل سبد سهام** حساب می‌شود، نه جمع اوج جداگانهٔ هر نماد. بهای سهم‌هایی که تا پایان هر روز فروخته شده‌اند در موجودی همان روز نیست، اما فروش‌های بعدی اوج ثبت‌شدهٔ روزهای قبل را پاک نمی‌کنند. ماندهٔ نقدی حامی و نوسان قیمت بازار نیز وارد آن نمی‌شوند. چون ساعت واقعی سفارش‌ها ثبت نشده، اوج میان‌روز را حدس نمی‌زنیم؛ تاریخ نمایش‌داده‌شده پایان نخستین روز ثبت آن اوج است.

1. **سود محقق‌شده ÷ بیشترین پول درگیر بورس**: صورت، سود/زیان فروش‌ها (مبلغ خالص فروش منهای بهای میانگین سهم‌های فروخته‌شده) به‌علاوهٔ سود مجمع پرداخت‌شده است. مخرج اوج بهای خریدِ هم‌زمان سهام است، نه مجموع همهٔ خریدهای تاریخی یا فقط بهای سهم‌های فروخته‌شده.
2. **سود فعلی ÷ بهای خرید سهام موجود**: صورت، ارزش روز سهامِ هنوز موجود منهای بهای خرید همین سهام پس از فروش‌های جزئی است؛ سود فروش‌های قبلی و مجامع (پرداخت‌شده یا در انتظار) در این نسبت نمی‌آیند. مخرج این نسبت تغییر نکرده است.
3. **سود کل ÷ بیشترین پول درگیر بورس**: صورت، مجموع سود محقق‌شدهٔ بند اول، سود قیمتی بند دوم و مجامع در انتظار پرداخت است؛ مخرج همان اوج بهای خرید هم‌زمان است. درصد کارت «بورس» در «دارایی‌ها» نیز همین نسبت سوم است. وضعیت مجمع از «در انتظار» به «پرداخت‌شده» که تغییر کند، سود کل ثابت می‌ماند ولی ترکیب محقق‌شده/نشده عوض می‌شود.

هر سه مقدار در ۱۰۰ ضرب و به درصد تبدیل می‌شوند؛ اگر مخرج یکی صفر باشد به‌جای درصد «—» دیده می‌شود. این‌ها **نسبت‌های سادهٔ سود به بهای خرید** هستند، نه بازده سالانه، بازده سرمایهٔ اولیه، آوردهٔ خالص نقدی یا بازده جریان‌های نقدی: سودِ فروش اگر دوباره سرمایه‌گذاری شود می‌تواند خودِ بهای خرید هم‌زمان را بالا ببرد. نسبت‌های گزارش کل پرتفوی مخرج‌های جداگانه دارند. درصد جاری و سود کل به آخرین قیمت‌های **ثبت‌شده** وابسته‌اند، نه الزاماً قیمت زندهٔ بازار.

## هشت شاخص در «گزارش‌ها»

خلاصهٔ بالای گزارش، مستقل از باز بودن بخش جزئیات، کل سرمایهٔ اولیه و آورده‌های بعدی، سود محقق‌شده، جمع سود محقق‌شده و جاری، ارزش روز دارایی‌های فعلی، بهای خرید موجودی فعلی و سه نسبت را نشان می‌دهد:

- **سود محقق‌شده ÷ (سرمایهٔ اولیه + آورده‌های بعدی)**؛
- **(ارزش روز دارایی‌ها + سود محقق‌شده) ÷ سرمایهٔ اولیه** (نسبت قبلی بدون تغییر)؛
- **(ارزش روز دارایی‌ها + برداشت بیرونی + سود محقق‌شده) ÷ (سرمایهٔ اولیه + آورده‌های بعدی)** (کارت جدید).

برداشت بیرونی در صورت کارت جدید اضافه می‌شود، اما از مخرج هیچ‌یک از نسبت‌ها کسر نمی‌شود؛ انتقال بین حساب‌های داخل سبد، خریدوفروش داخلی و برداشت‌های هنوز تأییدنشده «برداشت بیرونی» نیستند. در نسبت دوم، آورده‌های بعدی به مخرج اضافه نمی‌شوند؛ در نسبت سوم می‌شوند. اگر مخرج مربوط به هر نسبت معلوم و مثبت نباشد، درصدی حدس زده نمی‌شود. ارزش روز شامل ماندهٔ نقدی است؛ بنابراین افزودن سود محقق‌شده‌ای که هنوز در نقد مانده ممکن است به دوباره‌شماری منجر شود. هیچ‌کدام بازده سالانه نیستند و دو نسبت آخر بازدهی خالص هم نیستند.

سود محقق‌شده شامل سود/زیان فروش دارایی و سهام، سود مجمع **پرداخت‌شده** و سود واریزی حساب‌های نقدی (با کسر هزینه‌های ثبت‌شده) است؛ سود مجمع پرداخت‌نشده جزو سود محقق‌شده نیست. بهای خرید موجودی فعلی فقط موقعیت‌های باز را با بهای تمام‌شده‌شان و ماندهٔ حساب‌های نقدی را با ارزش اسمیِ امضادار در نظر می‌گیرد. اعداد از داده‌های ثبت‌شده محاسبه می‌شوند، نه از حدس دربارهٔ منشأ سرمایه؛ تا زمان رفع هشدارهای تطبیق، مقادیر و نسبت‌های نمایش‌داده‌شده «خام و نیازمند بررسی» هستند. حتی نبودِ هشدار داخلی جای تطبیق با صورت‌حساب‌ها را نمی‌گیرد.

## توسعه و کنترل

```bash
npm test
npm run lint
npm run build
```

نسخهٔ منتشرشده را از صفحهٔ Releases بگیرید؛ گزینهٔ **Code → Download ZIP** در صفحهٔ اصلی مخزن ممکن است مربوط به شاخهٔ `main` و نسخه‌ای متفاوت باشد.
